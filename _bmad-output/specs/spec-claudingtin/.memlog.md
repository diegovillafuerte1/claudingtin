- (capability) CAP-1 Think-time detection auto-enqueue: companion tails the CC transcript, enters queue on burst start, ends chat on burst end unless persist on. PRD F1, FR1-4; AD-6/AD-7.
- (capability) CAP-2 FIFO pairing: backend pairs strictly first-in-first-out, no scoring, skipping block/cooldown/ban-ineligible pairs. PRD F2, FR7-12; AD-1/AD-8/AD-16.
- (capability) CAP-3 Ephemeral text chat surface: text-only companion pane, peer pseudonym/blurb + current-chat history + input + block/report/leave controls, memory-only relay. PRD F3, FR13-18; AD-3/AD-10/AD-15.
- (capability) CAP-4 No-rejection exit convention: every chat-end presented identically as 'their Claude came back'; wire session_ended carries no cause; mid-burst disconnect silently re-queues. PRD F4, FR19-21; AD-4/AD-16/AD-17.
- (capability) CAP-5 Persist toggle (default-on) + session-ID keepsake offered when a persisted chat ends; ID opaque and inert in v1. PRD F5, FR22-26; AD-4.
- (capability) CAP-6 Tiny optional profile: pseudonym + short blurb, backend copy canonical, in-plugin editable; one optional skippable match-preference hint with no v1 effect; forget-me deletes all keyed state except bans. PRD F6, FR27-29; AD-9; NFR4.
- (capability) CAP-7 Curated rotating openers: one repo-maintained pre-written opener per match, identical on both sides, not generated per-match. PRD F7, FR30-31.
- (capability) CAP-8 Block, auto-cooldown, rate limiting: one-action permanent block keyed to account key and independent of preferences; ~24h auto-cooldown after a real pairing; per-key match-rate/msg-rate limits + exactly 1 concurrent chat. PRD F8, FR32-36; AD-2/AD-8.
- (capability) CAP-9 Reporting + maintainer moderation: one-tap report (also blocks) capturing last ~20 msgs of that chat only; out-of-band delivery; CLI ban effective within ~10s. PRD F9, FR37-42; AD-10/AD-13/AD-15.
- (capability) CAP-10 Keyword filter + link inerting: backend strips/inerts links, rejects non-text/oversized frames on ingest, applies a repo-maintained keyword filter before relay; companion renders peer text literally. PRD FR14/FR49, NFR11; AD-15.
- (capability) CAP-11 First-run onboarding + 18+ gate: local-only screen (what it is, honest safety warning, block/report explainer, affirmative 18+ attestation) before any network call; declining leaves plugin inert. PRD F10, FR43-46; AD-2 carve-out.
- (capability) CAP-12 Empty-queue 'leave a note': after a threshold wait, user may leave a short ephemeral note the next arrival sees as their opener and can reply to; in-memory only, same text/link/keyword rules. PRD F11, FR47-51; AD-16.
- (capability) CAP-13 Fail-open host integration: SessionStart hook spawns companion once, detached, returns immediately (<=~50ms); every failure swallowed, nothing surfaces in the CC UI. PRD FR6/NFR6/NFR8; AD-14.
- (capability) CAP-14 Self-hostable backend + maintainer status: single image, one-command self-host defaulting to public instance URL as client, env-var-only config, GET /status metrics, no admin HTTP surface. PRD NFR13-15; AD-12/AD-13.
- (constraint) Claude Code only in v1 — think-time is detectable only via the CC session transcript/hooks; no claude.ai, no Claude Desktop, no web client. PRD NG6; addendum 2.
- (constraint) Nothing about chat content is persisted anywhere (client or server); relay is memory-only. Sole exception: a report payload (last ~20 msgs of one chat), deleted once actioned. PRD FR15/NFR1; AD-10.
- (constraint) Backend is the single authority for all matching and moderation policy (identity acceptance, eligibility, rate limiting, keyword filtering); the open-source companion never gates on policy locally. Carve-out: first-run 18+/safety gate is a local companion precondition, no server round-trip, no attestation record. AD-2.
- (constraint) Hub-and-spoke only: all queue/pairing/session state lives in the backend and only there; companions hold no authoritative state and never talk companion-to-companion. AD-1.
- (constraint) Identity = a random UUID created once at a stable OS-config path outside the plugin dir, presented in hello, trusted by the backend with no verification. No Claude-account linkage is possible. Ban/block evasion by a motivated user is accepted. PRD FR41/OQ-3; AD-11.
- (constraint) The plugin must never block, delay, or error the host Claude Code session — fail open on every failure path; a hook returns in <=~50ms. PRD FR6/NFR6; AD-14.
- (constraint) Text only, no media, links inert — the safety keystone; removes the CSAM-image/nudity/malware-link surface that sank video competitors. PRD FR13-14; addendum 1.
- (constraint) 18+ only, self-attested; no ID checks, no age estimation, no minor-safe mode. Residual regulatory risk accepted and documented. PRD FR44/OQ-A.
- (constraint) Single backend instance in v1 (one SQLite file, no horizontal scale). Sized for low-hundreds concurrent users on one small cloud instance; hosting target < ~20 USD/mo (~5-10 USD/mo real Fly bill). PRD NFR9/NFR13; spine Stack.
- (constraint) FIFO with no matching algorithm and no preference weighting in v1 — the optional 'prefer to be matched with' hint is stored only to seed v2 and has zero v1 effect. PRD NG2/NG7/FR7.
- (constraint) Reactive moderation only — reports + block + rate limits + keyword filter + fast bans; no proactive or ML content scanning. Documented NCMEC path on actual knowledge of CSAM. PRD 8; addendum 1.
- (constraint) Public instance operated by the maintainer as an individual, no legal entity; ToS and privacy policy authored in their personal name. PRD OQ-C.
- (constraint) Wire protocol is versioned JSON defined once in /proto; backend accepts current + previous minor, older gets please_update then close. AD-3/AD-5.
- (constraint) All client<->server traffic over TLS/WSS; server treats all message content as untrusted — no remote markup/HTML rendering, input length caps. PRD NFR10-11; AD-15.
- (constraint) Implementation stack and topology are fixed by the adopted architecture spine: Go 1.27, Bubble Tea v2 companion TUI, coder/websocket, pure-Go modernc.org/sqlite, Fly.io single machine + volume; monorepo /plugin /companion /backend /proto. See ARCHITECTURE-SPINE.md.
- (constraint) User-facing copy is warm, light, human — never corporate, clinical, or therapized; exit copy is a cheerful 'catch you later' with no apology or 'are you sure?'; searching->matched has a brief non-blocking flourish. PRD NFR16-19. See voice.md.
- (constraint) No paid acquisition and no bot/fake-user queue fill; launch into a single beachhead community, optionally with scheduled power-hour windows. PRD 9; addendum 1.
- (note) Non-goals: engagement/session-length/DAU/retention optimization (counter-metrics); matching/recommendation engine in v1; help desk / expertise marketplace / work-collab tool; general social network (friend graph, feed, persistent DMs); minors / minor-safe mode; claude.ai or Claude Desktop client in v1; the v2 reconnect webapp, missed-connections board, interest tags, pull-in matching; voice/video/image/file sharing; proactive/ML content scanning; paid tiers, monetization, ads; post-chat rating or satisfaction survey. PRD 12, NG1-7.
- (note) Success signal: primary M1 — median time-to-match < ~15s during active hours, measured server-side queue-enter to pairing. Outcome proxy M2 — repeat use + organic spread (installs still queuing weeks later, beachhead word-of-mouth, self-hosted pools). Failure indicators C1-C3 — session length trending up over weeks, DAU becoming a design focus, reports per 100 chats rising.

- (assumption) Tool-call boundaries within one turn are one continuous burst -> at most one match per user turn. PRD FR3.
- (assumption) If the two longest waiters are ineligible for each other, the backend skips to the next eligible pair rather than stalling. PRD FR9; AD-8.

- (assumption) Rate-limit starting bounds: <=1 new match / ~10s, <=~5 messages/s, exactly 1 concurrent session. PRD FR36.
- (assumption) Report captures the last ~20 messages of that chat only. PRD FR38. Exact N = OQ-8.
- (assumption) Reconnect grace window ~10s; CLI ban takes effect within ~10s (re-read interval / SIGHUP). AD-13/AD-17.
