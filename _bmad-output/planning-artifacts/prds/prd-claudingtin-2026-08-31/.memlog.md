- (decision) Core purpose: address loneliness among AI-heavy Claude users; success = genuinely reducing that felt loneliness, not engagement metrics for their own sake.
- (decision) Stakes: open-source, adoption-serious (~4-6pp). Scope = buildable MVP + articulated v2 roadmap (session IDs, missed-connections board, pull-in). Working mode: Fast path (batch gaps, draft with [ASSUMPTION] tags, iterate).
- (decision) Delivery: Claude Code plugin + hooks. Think-time start approximated by UserPromptSubmit, end by Stop hook. Chat surface = companion process/terminal pane; messages relayed to hosted matching server over websocket.
- (decision) Backend: single hosted public instance, minimal state. In-memory: queue, active pairings, message relay. Persisted: tiny profile, block list, cooldown timers. Chat message content never persisted.
- (decision) Identity: Claude-linked pseudonymous. Stable user key = hash of Claude account id -> enables durable blocks/bans, reliable cooldown, rate limits. Others see pseudonym + optional tags only. 18+ self-attestation at first run.
- (decision) Primary operational success metric (Diego's pick): healthy liquidity - median time-to-match < ~15s during active hours. Explicit non-goal: optimizing time-in-app / DAU / retention.
- (assumption) [ASSUMPTION] North-star outcome metric added by facilitator: post-chat one-tap 'glad I talked to them' % with counter-metric 'made me feel worse' %. Needs Diego confirm - he selected only liquidity.
- (decision) Research-driven: text-only chat, no media, outbound links stripped/disabled in MVP. Rationale: collapses CSAM/legal/abuse surface for a small OSS project; ephemeral-by-default means little to subpoena.
- (decision) Cold-start strategy: launch scoped to ONE existing community (a specific Claude/AI Discord or subreddit) not 'all lonely Claude users'; support power-hour events; empty-queue fallback = 'leave a note for the next person' which feeds the v2 missed-connections board.
